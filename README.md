# Information Retrieval Project

## Project Description
This project implements a text preprocessing system for Information Retrieval using Python.

## Preprocessing Steps

The program performs four main preprocessing operations:

1. **Tokenization:** Splits the input text into individual tokens.
2. **Normalization:** Converts uppercase letters to lowercase and standardizes abbreviations.
3. **Stop Words Removal:** Removes common English words that have limited importance.
4. **Stemming:** Removes selected suffixes to convert some word variations into a common form.

## Evaluation

The program compares its output with a manually prepared Gold Standard.

The evaluation metrics include:

- Precision
- Recall
- F1-Score

It also displays extra and missing words.

## Test Data

The program is tested using three sample texts provided in the project instructions. It also supports processing custom text entered by the user.

## How to Run

1. Download the Python file.
2. Open a terminal in the project folder.
3. Run:

```bash
python Mani_Golshahi.py
```
